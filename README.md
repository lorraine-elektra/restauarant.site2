# Hajia’s Kitchen

A responsive, single-page static restaurant website for Hajia’s Kitchen, designed to showcase Ghanaian cuisine, restaurant identity, and customer ordering in a clean and accessible web interface.

## Overview

Hajia’s Kitchen is a fully static restaurant website built as a portfolio project. It presents structured menu content, brand storytelling, and an order request system within a single-file architecture (`index.html`). The design prioritizes responsiveness, usability, and simplicity across devices.

---

## Features

* Responsive single-page layout with mobile-friendly design
* Sticky navigation with smooth scrolling between sections
* Structured menu system with categorized dishes and pricing
* Restaurant story section communicating brand identity and background
* Integrated media support for branding assets (`logo.png`, hero images)
* Order form with client-side validation
* Optional backend integration via Formspree or compatible form endpoints
* SEO-ready structure with meta tags and Schema.org Restaurant markup
